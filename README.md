# 🚕 Cab Booking and Fare Calculation System

A simple Java-based cab booking application that allows users to select a cab type, enter their travel distance, and calculate the total fare.

This mini project was developed as part of my **Java Full Stack training with Linkzie Tech**, under the guidance of **Mr. Aryan Gupta, Technical Trainer**.

---

## 📌 Project Overview

The application simulates a basic cab booking service.

A customer can:

1. Enter their name.
2. Select a cab category.
3. Enter the travel distance.
4. Calculate the total fare based on the selected cab.
5. View the booking confirmation and fare details.

The project uses multiple Java classes to represent different types of cabs and demonstrates how **Object-Oriented Programming concepts** can be applied to a simple real-world scenario.
